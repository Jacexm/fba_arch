# FastAPI Best Architecture 学习讲义规划

## 讲义目标

你当前具备 Python/FastAPI/MySQL 基础，也有 Spring Boot 的工程化经验。本讲义的目标不是重复基础语法，而是帮助你建立 Python 企业级后端的系统化工程思维：

1. 理解项目整体架构与模块边界。
2. 掌握伪三层架构在 FastAPI 中的落地方式。
3. 熟悉核心工程能力：配置、数据库、认证授权、中间件、缓存、可观测性。
4. 形成“可扩展、可维护、可观测”的后端设计习惯。

## 文档风格与范围

- 风格：技术文章风格，关键代码片段 + 实现原理 + Mermaid 图。
- 深度：深入型，每篇聚焦核心实现与设计决策。
- 范围：不讲部署细节，重点放在代码架构与工程实践。
- 组织方式：按学习路径递进，而非纯目录罗列。

## 学习路径

### Phase 1 项目入门

1. 1.项目总览与技术栈.md
2. 2.应用启动流程深度解析.md
3. 3.伪三层架构设计详解.md

目标：先建立“系统全貌 + 关键主线”。

### Phase 2 核心基础

4. 配置系统与依赖注入
5. 数据库层（异步引擎与连接池）
6. 模型设计与 Alembic 迁移
7. CRUD 封装与查询构建

目标：掌握后端内核能力。

### Phase 3 业务实现

8. 统一响应与异常处理
9. Admin 模块（用户与角色）
10. Admin 模块（权限与菜单）

目标：把架构能力落到真实业务。

### Phase 4 安全与权限

11. JWT 认证机制
12. RBAC 权限系统
13. 数据权限过滤

目标：理解“认证 + 授权 + 数据边界”的完整链路。

### Phase 5 基础设施

14. 中间件执行链与请求上下文
15. 多级缓存系统
16. 国际化与日志系统

目标：构建可维护、可调试的运行时基础。

### Phase 6 可观测性

17. 日志与链路追踪
18. 指标与监控

目标：让系统可度量、可诊断。

## 每篇文档模板

1. 概述：本章解决什么问题。
2. 核心概念：术语与设计原则。
3. 架构设计：模块关系与职责。
4. 核心实现：关键代码片段与解读。
5. 执行流程：Mermaid 图梳理主链路。
6. 最佳实践：常见坑与建议。
7. 小结：本章结论与下一章连接点。
